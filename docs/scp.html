SCP（Service Control Policies）

組織全体およびOUに適用する、AWS操作のガードレール。

ドキュメント

  • ドキュメントトップ
  • AWS Organizations

  • タグポリシー
  • IAM Identity Center

方針

SCPは「許可」ではなく「禁止」を中心に管理し、例外は最小限にします。

設定内容

SCP適用先禁止する操作
guardrailsRoot OU組織からの離脱、rootユーザーの利用、IAMユーザー・アクセスキーの作成、CloudTrail・Config・GuardDuty・Security Hubの停止・削除
region-restrictionRoot OU許可リージョン（allowed_regions）以外の利用。IAM、Organizationsなどのグローバルサービスは除く
security-ousecurity OUログ保管用S3バケット（名前にlog-archiveを含む）の削除・設定変更、EC2・ECS・EKS・Lambda・RDSの作成

セキュリティサービスの停止禁止とリージョン制限は、scp_exempt_role_namesのロール（既定はOrganizationAccountAccessRole）を対象外にします。aws-foundationリポジトリから各アカウントのセキュリティサービスを設定するためです。

ログ保管用S3バケットとそのオブジェクトの削除は、除外ロールを含めて誰にも許可しません。古いログの削除はS3のライフサイクルルールで行います。

対象・集約先

  • 対象アカウント：全アカウント
  • 集約アカウント：-

注意点

  • SCPはmanagementアカウントには適用されない
  • 1つの対象に付けられるSCPは最大5つ（既定のFullAWSAccessを含む）
  • SCPは1つあたり最大5,120文字
